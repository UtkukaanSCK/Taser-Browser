# v0.3 manual checklist

What the in-app self-test (`--features selftest`) cannot prove. The self-test
installs from a fake store, never reaches the real Chrome Web Store, never
starts other applications, and cannot see or press keys in WebView2's
browser-process windows (extension popups' native frames, Edge-branded
dialogs). Run this list on a release build (`cargo build --release`) before
v0.3 ships. Every step is done by a person at the keyboard; nothing here
sends input to the desktop automatically.

Use a scratch profile unless a step says otherwise: point `LOCALAPPDATA` and
`APPDATA` at an empty folder for the command that starts
`target\release\x-browser.exe`. Profile data then lives in
`<scratch>\X-Browser`; `<data>` below means that folder.

For each line, write the date, the Windows/WebView2 version and OK or what
went wrong. Lines marked **open point** have no agreed answer yet: write down
what happens.

## First run (uBOL)

- [ ] Start with an empty scratch profile and a working network. Within a few
      seconds of the window appearing, uBlock Origin Lite shows up (its
      toolbar button, and later the Uzantılar page). No question or dialog
      is shown for it. `<data>\extensions.json` holds
      `"first_run_ubol": "done"`.
- [ ] On that first start, open a page that loads a known ad host (for
      example a news site with display ads, or a test page that requests
      `https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js`). The
      ad request is blocked (no ad frame; the uBOL popup counts blocked
      requests for the page).
- [ ] Start with an empty scratch profile and the network off. The browser
      starts normally, with no error dialog, and `first_run_ubol` stays
      `"pending"`. Turn the network on and start again: uBOL arrives.
- [ ] Close and start again with uBOL installed. It is not downloaded a
      second time (no new folder under `<data>\extensions\`, start-up feels
      the same).

## uBOL and the Uzantılar page

- [ ] Open the uBOL popup from the toolbar on an ordinary site. It shows that
      site's name (not "not a website"). Switch the filtering mode for the
      site (for example to "no filtering"), reload: the ads blocked before
      now load. Switch back, reload: they are blocked again. (uBOL asks
      only for `activeTab`, a path the self-test extension, which has
      `tabs`, does not cover: "not a website" here means the popup's
      `tabs.query` got no address.)
- [ ] uBOL's dashboard / options opens in a tab and its settings can be
      changed.
- [ ] On the Uzantılar page, turn uBOL off: the toolbar button goes away and
      ads load after a reload. Turn it on again: blocking resumes. The
      on/off state survives a restart.
- [ ] On the Uzantılar page, remove uBOL. X-Browser asks first; after "yes"
      it disappears from the page and the toolbar, and
      `first_run_ubol` becomes `"user_removed"`.
- [ ] Restart (twice). uBOL does not come back, and nothing is downloaded for
      it. Installing it by hand from the store still works.

## Chrome Web Store page (Dark Reader)

Use the real store page for Dark Reader
(`https://chromewebstore.google.com/detail/eimadpbcbfnmbkopoojfekhnkhdbieeh`).

- [ ] Install with the toolbar "Ekle" button while the store page is open.
      X-Browser's own question appears, naming the extension and its
      permissions in Turkish. Edge's "Add … to Microsoft Edge?" dialog never
      appears. After "yes", Dark Reader works on a page.
- [ ] Remove it, then install with the store's own "Add to Chrome" button.
      Again X-Browser's question appears, never Edge's.
- [ ] Answer "no" to X-Browser's question once: nothing is installed and no
      folder is left under `<data>\extensions\`.
- [ ] With Dark Reader installed, reload the store page: its button now says
      "Remove from Chrome" ("Kaldır" in a Turkish store page).
- [ ] Press the store's remove button. X-Browser asks first; after "yes"
      Dark Reader is gone from the Uzantılar page and the toolbar, and the
      store page offers "Add" again after a reload.
- [ ] **Open point:** an extension that declares optional permissions (find
      one on the store, or note which one you used) asks for them at run
      time. Write down whether a question appears, whose question it is
      (X-Browser's or Edge's), and whether the grant works.

## Updates

- [ ] **Open point:** with an older version of an extension installed under
      its store id, install a newer version of the same id (the update
      path). Write down whether `AddBrowserExtension` accepts it in place
      or refuses it.
- [ ] Before the update, change a setting in the extension (Dark Reader:
      brightness; uBOL: a filtering mode for one site). After the update
      the setting is still there (`chrome.storage` kept). Removing and adding
      again is known to wipe it, so an update must never be done that way.

## Clearing browsing data

- [ ] Change a uBOL setting (a per-site filtering mode). Clear browsing data
      from the settings page. Cookies, history and cache are gone; the uBOL
      setting is still there and uBOL still blocks ads.
- [ ] Same with Dark Reader installed: its settings and its on/off state
      survive the clear.

## Popups and accessibility

- [ ] Open an extension popup (uBOL). Esc closes it and focus returns to the
      page or the toolbar.
- [ ] Open it again and click outside it (on the page, on the tab strip):
      it closes.
- [ ] Open it, then move or resize the window: it closes or stays attached
      to its button; it never floats somewhere else.
- [ ] In a popup with a frame in it, click a `mailto:` link inside the frame
      (the self-test cannot confirm WebView2 raises the launch event there).
      No mail app opens, no question appears, and the popup stays open.
- [ ] Uzantılar page with Narrator (and NVDA if available): each extension
      is read with its name, its state (on/off) and its source; the on/off
      switch and "Kaldır" are reached with Tab and read by name; Space or
      Enter works them; the removal question is read as a question.
- [ ] Uzantılar page by keyboard only: every control is reachable, the focus
      ring is visible in light and dark theme.

## Unregistered extensions and a lost extensions.json

- [ ] Get an extension into the profile from outside X-Browser's record (for
      example accept Edge's own dialog if it ever appears, or add one with a
      separate WebView2 host on the same user-data folder). On the next
      start it is turned off, and the Uzantılar page lists it with an
      "unknown source" label. It can be removed from there.
- [ ] **Open point:** with uBOL installed, close X-Browser, delete
      `<data>\extensions.json` and its `.bak`, and start. Write down whether
      uBOL stays turned off (it is unknown to the record) or comes back on,
      and whether the first-run logic installs it again.

## Start-up time and size

Use the README "Startup timing" method: release build, scratch profile, one
blank tab, one warm-up, then 10 runs 8 s apart, median of each milestone.

- [ ] Interleave v0.2 and v0.3 (v0.2 run, v0.3 run, and so on) on the same
      machine in one sitting, each with its own scratch profile. Record the
      medians for `window-shown`, `ui-webview-created`,
      `first-tab-created` and `ui-ready`. Budget: v0.3's `ui-ready` median
      is at most 100 ms above v0.2's.
- [ ] Repeat for v0.3 with uBOL installed (a profile after the first run).
      Record the medians.
- [ ] Record both binary sizes in bytes and add the rows to the README table.
- [ ] Record the disk use of `<data>\extensions\` after uBOL has run once
      (about 47 MB expected, most of it uBOL's indexed rulesets).

## Junction for the extensions folder

- [ ] Close X-Browser. Move `<data>\extensions` elsewhere and put a real
      junction in its place (`mklink /J <data>\extensions <elsewhere>`).
      Leave a half-written folder inside (for example `<version>.tmp` under
      an extension id). Start: X-Browser deletes nothing under the junction,
      the leftover is still there, and the browser starts normally.
- [ ] With the junction in place, remove an extension from the Uzantılar
      page. Nothing is deleted through the junction; write down what the
      page shows and whether the entry stays hidden as `removed`.
- [ ] Remove the junction and move the folder back. The next start cleans
      the leftovers.

## Certificate errors and the own error page

- [ ] Open `https://expired.badssl.com/` and `https://self-signed.badssl.com/`.
      Each ends on X-Browser's own error page, not Edge's warning, and
      nothing on it (no link, key or hidden "proceed" control) loads the
      site anyway. The lock shows the error, and reloading gives the same
      page.
